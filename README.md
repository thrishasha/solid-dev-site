# Senior Coder Hub

Build a modern, premium, professional, responsive developer portfolio website for a Software Developer with real-world backend and full-stack engineering experience.

Core Goal

Create a portfolio that feels like a senior software engineer's professional portfolio, not a generic template. Emphasize real-world engineering experience, problem-solving, backend architecture, API development, databases, SaaS applications, healthcare/LIMS systems, and production-oriented development.

Design Direction

Use a premium developer-focused visual design:

Dark mode as the primary visual style

Light mode toggle

Strong typography

The design should communicate:

"Professional Software Engineer who builds real-world systems."

Do NOT make it look like a gaming portfolio, crypto website, or overly animated template.

Animations

Use animations carefully:

Hero text entrance

Smooth section reveal

Scroll-based animations

Project card hover effects

Button micro-interactions

Smooth page transitions

Subtle Particle.js background

Particle.js must remain subtle and performance-friendly. It should enhance the design rather than distract from the content.

Respect prefers-reduced-motion and provide reduced/no animations for users who request it.

Important Content Principle

Do not use generic filler such as:

"I am passionate about coding and love creating amazing websites."

Instead, emphasize measurable and technical engineering work such as:

Backend API development

REST and GraphQL API integration

Laravel/PHP development

Authentication and authorization

SaaS architecture

Healthcare/LIMS workflows

Database migrations

Production-oriented problem solving
